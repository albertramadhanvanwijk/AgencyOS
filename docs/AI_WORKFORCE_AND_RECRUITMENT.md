# AI Workforce and Recruitment
## Role catalog templates
Product/Research: Product Owner, Product Manager, Business Analyst, Technical BA, Business Researcher, Solution Architect, Technical Writer. Delivery: Project Manager, Scrum Master, Sprint Planner, Delivery Manager, AI Task Coordinator, Project Analyst. Design: UI/UX Designer, UX Researcher, Product Designer, Interaction Designer, Visual Designer, Design System Specialist, UX Writer, Accessibility Specialist, Prototype Specialist. Engineering: Engineering Lead, Frontend Engineer, React/Next.js Specialist, UI Implementation Specialist, Backend Engineer, API Engineer, Database Engineer, Integration Engineer, Auth/Authz Specialist, Performance Engineer, Full-stack Engineer, Mobile/iOS/Android/Desktop Engineer, AI/ML Engineer, Agentic AI Engineer, Data Engineer. Quality: QA Engineer, Manual Tester, Automation Test Engineer, Integration/Performance Test Engineer, Security Engineer, Code Reviewer, Release Validator. Platform: DevOps, Cloud, Infrastructure, SRE, Containerization, Database Reliability, Observability, Release Engineer. Client Delivery: Account Manager, Client Requirements Analyst, Implementation Specialist, Support Agent, Documentation, Training, Maintenance Engineer. Business Ops: Sales Researcher, Solutions Consultant, Proposal Writer, Estimator, Marketing Strategist, Content Specialist, Finance Analyst, Operations Analyst. These are templates, not mandatory live agents.
## Agent profile
Identity/purpose; role/department; declared and verified skills; instructions; allowed tools; adapter; input/output contract; permissions; concurrency/budget; timeout/retry; escalation; qualification suite; version history. Separate role, agent, project and run context. Never put project secrets in global profiles.
## Recruitment decision engine
Inputs: queued/blocked work by skill, workload/capacity, deadline/sprint goal, qualification evidence, priority, budget, alternatives, engine health/rate limits. Output: recruit/reassign/wait/reduce scope/request concurrency, with evidence, assumptions, expected impact, cost/risk, confidence and approval. Queue length alone is not enough; distinguish temporary spikes from sustained bottlenecks.
## Lifecycle
Draft request → demand/capacity analysis → human approval → create distinct identity/profile → isolated qualification → human review → approved activation → project assignment/capacity → monitoring → retirement/archival. Lifecycle: Draft, Pending Approval, Testing, Active, On Leave, Paused, Retiring, Archived. Availability: Available, Busy, Capacity Limited, Offline, Error. Qualification: Not Tested, In Progress, Passed, Passed with Restrictions, Failed, Requires Revalidation. Keep dimensions separate.
## Staffing and performance
Stable core team plus dynamic specialists. Scheduler checks skill, qualification, permission, capacity, budget, availability and dependencies. Do not transfer project context implicitly. Track acceptance/rework/defects/time/test rate/cost/reliability with sample size and task difficulty context; avoid one opaque score for automatic decisions.
## Human approval by default
New official role, new agent activation, permission expansion, spend threshold, new external side-effect integration, organization-wide policy change.
