# Project Brief
## Vision
Operate a software development agency through a structured, human-supervised AI workforce. Manage departments, job roles, agent identities, recruitment, projects, Scrum, execution, reviews, approvals, isolated workspaces, and delivery reporting in one platform.
## Problem and outcome
A collection of coding assistants lacks agency-wide staffing, multi-project resource planning, Scrum accountability, isolation, approval policies, and auditable delivery. The user should be able to create an agency workspace, configure and qualify agents, recruit new identities with approval, create projects, assemble stable core teams plus dynamic specialists, manage backlogs/sprints, execute authorized work in isolated workspaces, inspect evidence, and monitor delivery.
## Users
Agency Owner/Human Supervisor; Product Owner/Project Lead; Scrum Operator; Workforce Manager; Technical Reviewer. Initial use may be single-user, but do not hard-code a permanently single-user permission model.
## Operating model
Agile Scrum; Human-Supervised AI Scrum; hybrid teams; shared workforce and scheduler; project-specific Scrum, repository/workspace, context, permissions, and secrets. Human approval for new official roles, new agent activation, privilege expansion, production deployment, destructive operations, and policy/budget changes.
## MVP non-goals
Training foundation models, unrestricted self-modifying agents, unapproved production deployment, premature microservices/Kubernetes, unverified integrations, full SaaS billing.
## First end-to-end milestone
Create a project, configure an agent, create a Scrum work item with acceptance criteria, run a clearly labelled mock execution through an adapter, review evidence, update status, and inspect the audit trail.
