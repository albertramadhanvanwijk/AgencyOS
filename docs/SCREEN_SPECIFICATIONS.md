# Screen Specifications
## Agency Overview
Portfolio table (project, health, sprint progress, blockers, next milestone, owner); pending approvals; workforce capacity; evidence-backed risks and next action; recent activity. Avoid unrelated metric cards.
## Project Directory and Summary
Search/filter projects; create project; show status, sprint, blockers, team, activity. Summary shows goal, sprint progress/scope changes, work-item status, blockers/dependencies, team capacity, recent runs/quality failures and links to project areas.
## Scrum Board
Configurable columns; cards show key/type/title/priority/assignee/blocker/dependency. Validate drag transitions and explain denials; provide keyboard alternative. Filters by sprint, assignee, type, priority, label. Dense but readable.
## Backlog/Sprint Planning
Hierarchical epic/story/task list; sprint goal/dates/capacity/committed work; warnings for capacity/dependencies; estimates and acceptance criteria; identify source of estimates.
## Work Item Detail
Key/type/title/status/priority/assignee; description, acceptance criteria/DoD, dependencies, parent/children, labels, sprint, comments/activity, run history, agent/profile/engine, diffs/artifacts/tests/review/approval. Audit details accessible but not overwhelming.
## Workforce Directory/Profile
Directory table: identity, role, department, skills, lifecycle, qualification, engine, assignments, capacity, recent outcome. Profile sections: role/skills, profile versions, engine/capabilities, permissions/tools, qualification evidence, assignments, performance evidence, lifecycle events. Actions edit/clone/test/assign/pause/retire; permission changes require approval.
## Recruitment Center
Queue; demand evidence/skill bottleneck; alternatives recruit/reassign/wait/reduce scope/increase concurrency; role requirements, qualification plan, cost/risk assumptions, approval, test results, activation. Label estimates/unknowns.
## Organization & Role Catalog
Department hierarchy, role list/details, responsibilities, skills, permission template, qualification checklist. AI-proposed roles remain separate until approved; audit changes.
## Execution Runs
Filter by project/status/agent/engine/date. Detail timeline, redacted logs, changed files, tests, artifacts, retries, approvals. Clearly label simulated runs. Only show cancel/retry when supported and authorized.
## Approvals and Settings
Approval queue shows exact action/scope/requester/evidence/consequences/policy reason; approve/reject/request changes with rationale. Settings for engine health, repository/workspace, policy, thresholds, budgets, backups/diagnostics. Integration states: Not configured, Configured, Verified, Error, Unsupported.
## Required states on every screen
Loading, empty, partial/no data, validation failure, permission denied, API/network error, stale data, success, destructive confirmation, keyboard focus, responsive layout. Label sample data.
